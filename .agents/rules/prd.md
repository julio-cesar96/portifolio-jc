# PRD - Portifólio Pessoal

## Problema

Atualmente o portfólio apresenta apenas informações institucionais.
Não existe um espaço para compartilhar artigos técnicos, estudos de caso e conteúdos produzidos pelo autor, formulário de contato, minhas experiencias, minhas habilidades

## Usuário

Recrutadores
Clientes
Desenvolvedores

## Objetivo

Permitir que visitantes leiam conteúdos produzidos pelo autor e entendam melhor sua experiência técnica.

## Funcionalidades

- Listagem de artigos
- Página de detalhe
- Data de publicação
- Tempo estimado de leitura
- Tags

## Fora do Escopo

- Comentários
- Sistema de login
- Newsletter

## Critérios de Sucesso

- Usuário consegue visualizar todos os artigos.
- Usuário consegue abrir um artigo.
- Usuário consegue navegar entre artigos.
